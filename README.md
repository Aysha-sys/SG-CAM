# SG-CAM: Segmentation-Guided Cross-Attention for Aerial Scene Classification

Code, data splits, result tables, figures and execution logs for the article

> **Semantic–Visual Feature Fusion via Cross-Attention for Remote Sensing Land-Cover Scene Classification**
> Alaa Menshawi, Aysha Naseer, Abrar Almjally, Meteb Altaf, Khaled Alnowaiser. *PeerJ Computer Science* (manuscript cs-132552, under review).

Every number in the article can be traced to a file in this repository: the result tables in `results/` are produced by the
reporting cells of the two notebooks from logged per-image predictions, and the execution logs record the actual runs.

## Method

| Component | Setting |
|---|---|
| Preprocessing | CLAHE on the L channel of LAB (clip limit 2.0, 8×8 tiles), resize to 256×256, ImageNet normalisation |
| Visual stream | MobileNetV2 (ImageNet-initialised, fine-tuned) → 1280 × 8 × 8 feature map |
| Semantic stream | SegFormer-B2 (`nvidia/segformer-b2-finetuned-ade-512-512`), **frozen**; 768-channel decoder features average-pooled to 8 × 8 |
| SG-CAM | Q from visual tokens, K and V from semantic tokens, d = 256, softmax(QKᵀ/√d)V, output projection, residual + LayerNorm |
| Head | Global average pooling → Dropout 0.5 → FC 512 → ReLU → FC 38 |
| Loss | Cross-entropy on scene labels only (no segmentation labels are used) |
| Training | Adam, lr 1e-4, batch 16, 15 epochs, StepLR (10, ×0.1), FP16; epoch selected on validation accuracy |
| Split | Stratified 60/20/20 train/validation/test, split seed 42 (`splits/patternnet_split.csv`) |

## Main findings (reported honestly in the article)

| Experiment | Visual-only baseline (B) | SG-CAM (C) | Test |
|---|---|---|---|
| PatternNet test accuracy (5 seeds) | 99.67 ± 0.03 % | 99.57 ± 0.06 % | Welch *t*, p = 0.009 (−0.11 pp) |
| Million-AID linear probe, balanced accuracy | 98.08 ± 0.89 % | 98.02 ± 0.92 % | no significant difference |
| Mean accuracy over 18 degradation settings | 73.67 ± 2.12 % | **77.36 ± 1.46 %** | paired *t*, p = 0.0017 (+3.69 pp) |

PatternNet is close to saturation and SG-CAM does not improve clean accuracy or linear-probe transfer; its benefit is robustness to
image degradation, chiefly additive Gaussian noise and haze, at roughly 40× the compute of the visual-only network.
Concatenation fusion (E) reaches a similar average robustness (77.24 ± 0.24 %) with a different per-degradation profile.

## Data

* **PatternNet** (Zhou et al., 2018): Kaggle dataset
  [`samitsaleem/patternnet-scene-classification-dataset`](https://www.kaggle.com/datasets/samitsaleem/patternnet-scene-classification-dataset)
  — 38 classes × 800 images, 256 × 256 px.
* **Million-AID** (Long et al., 2021): Hugging Face mirror
  [`jonathan-roberts1/Million-AID`](https://huggingface.co/datasets/jonathan-roberts1/Million-AID); the four *arable land*
  classes (dry field, greenhouse, paddy field, terraced field) are used. Notebook 02 downloads them automatically.

The datasets are not redistributed here; the split files identify every image used.

## Reproducing the results

### On Kaggle (as in the article)

1. Create a notebook from `notebooks/01_SGCAM_PatternNet.ipynb`, add the PatternNet dataset as an input and enable a GPU (T4).
2. `CFG["RUN_GROUPS"]` selects the experiment groups: `main`, `transfer_baselines`, `robustness_extra`, `ablation`,
   `sensitivity`, `backbones`. Kaggle sessions are limited to 12 h, so run the groups over several sessions; attach the output
   of the previous session as an input and finished runs are imported and skipped. `MAX_SESSION_HOURS` stops training safely
   before the limit.
3. Create a notebook from `notebooks/02_SGCAM_MillionAID_Transfer.ipynb`, attach the output(s) of notebook 01 (the checkpoints
   are discovered recursively) and the PatternNet dataset, enable internet access, and run all cells.

Each notebook writes `tables/`, `figures/`, `splits/` and a Markdown summary and packages them into a zip archive.

### Locally

```bash
pip install -r requirements.txt
# edit CFG["DATA_ROOT"] / CFG["OUT_DIR"] at the top of the script, then
python src/sgcam_patternnet.py
python src/sgcam_millionaid_transfer.py
```

A quick self-test on synthetic data (CPU, a few minutes) checks that the full pipeline runs end to end:

```bash
SGCAM_SMOKE=1 python src/sgcam_patternnet.py
SGCAM_SMOKE=1 python src/sgcam_millionaid_transfer.py
```

### Determinism

Seeds are fixed for Python, NumPy and PyTorch, but GPU convolution kernels are not fully deterministic; retraining a
configuration with the same seed can change test accuracy by up to about 0.1 percentage points. For the second execution round the released per-image
predictions reproduce the reported tables exactly; the output files of the first round were not retained by the Kaggle
session, so for those runs the execution log in `results/round1_patternnet/` is the record of the reported values.
